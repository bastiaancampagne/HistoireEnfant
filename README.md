# HistoiresEnfant PWA v2

Version PWA dérivée du dernier projet Android HistoiresEnfant_v2.

## Fonctions
- Accueil illustré avec l’émeu super-héros et le E sur la poitrine
- Phrase : « Pour Nhoa... et autres enfants sage. »
- Accès 5–6 ans et 7–8 ans
- Illustrations différentes selon les pages
- Installation iPhone/iPad/Android via l’écran d’accueil
- Service Worker pour l’interface hors connexion

## Important
Les deux pages d’histoires sont hébergées sur meshistoiresdusoir.fr.
Sur iOS, l’ouverture dans Safari / nouvel onglet est volontaire :
un site tiers peut interdire l’affichage dans une iframe/PWA intégrée.

## Déploiement GitHub Pages
Décompressez le ZIP puis envoyez le CONTENU à la racine du repository :
index.html, app.js, styles.css, sw.js, manifest.webmanifest,
icon-192.png, icon-512.png et le dossier assets/.
